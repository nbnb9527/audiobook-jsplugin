# audiobook-jsplugin（修改版）

Songloft / MiMusic 有声书插件的修改版。基于官方 `audiobook.jsplugin.zip` 原包，通过 `build.py` 自动提取源码、应用补丁、重新打包，**不改动官方包以外的任何二进制**，所有修改均可追溯（`build.py` 中每个补丁带编号与锚点断言）。

## 下载安装

从 [Releases](https://github.com/nbnb9527/audiobook-jsplugin/releases) 下载最新 `audiobook.jsplugin.zip`，在 Songloft 宿主插件页上传安装（或覆盖原插件目录后热重载）。

## 相对原版新增 / 修复的主要功能

### 一、大书库扫描修复（核心）

原版在书库规模上去后基本不可用，本版重点修复：

| # | 问题 | 修复 |
|---|---|---|
| P1 | 单本书音频数超过 65534 时 `push(...arr)` 参数超限，QuickJS 抛 RangeError 整本书丢失 | 改为分块 apply |
| P2 | 递归扫描深度硬编码 6 层，深层目录音频扫不到 | 提升到 20 层 |
| P3 | 逐文件串行 `await fs.stat`，SMB/NAS 上 19 万文件极慢且易触发宿主中断 | 16 并发批量 stat |
| P4 | 无法跳过超大素材目录 | 支持 `/app/audiobook/.scanignore` 配置忽略目录 |
| P5 | 嵌套书库（多级分类目录）扫描混乱 | 嵌套书库模式 v2，按子文件夹成书 |
| P6/P7 | 群晖 `@eaDir` 等缩略图目录被当成"有子目录"，每本书都生成"未分类合集"且丢封面/简介；含 `..` 的条目导致宿主 fs 整条拒绝 | 内置忽略名单（`@eaDir`、`@SynologyResource`、`#recycle`、`_ARCHIVE_TRASH`、`_DEDUPE_TRASH`、`@sharebin`），单本书内部同样跳过；`..` 条目剪枝 |

### 二、书名别名系统（解决有声书标题不能修改的问题）

- 编辑弹窗新增**别名字段**（保留原名提示），显示什么就能搜什么：关键词搜索、按书名排序均匹配别名。
- 排序支持显式 `asc/desc` 方向。
- 详情页/接口返回 `originalTitle` + `folderRelPath`，路径**只读展示 + 一键复制**。
- 旧版本存量 settings 自动深合并升级，不影响已有扫描记录与收藏/进度数据。

### 三、显示与浏览

- 主页工具栏新增**显示方式**（大图标/小图标/列表）与**顺序**下拉（排序 → 顺序 → 显示方式 → 只看收藏）。
- **多选 + 批量操作**：「全部书籍」标题后新增「多选」按钮进入多选模式——卡片左上角显示复选框（点卡片任意处即可勾选/取消），顶部批量工具栏支持**本页全选 / 本页反选 / 全选全部（跨页，跟随当前搜索与只看收藏过滤）/ 清除选择**，随后可执行**批量删除**（普通书删整个文件夹、合集删成员文件夹、未分类仅删音频，逐本带进度）、**批量收藏/取消收藏**（显式设置而非翻转）、**批量编辑**（简介前插/后插，分类/标签/作者 追加/替换/重设，封面重设）。
- 主页有声书图标和列表增加收藏、编辑和删除功能
- 设置弹窗可配置**默认显示方式**（桌面端/手机端独立记忆）。
- 分页区新增**页码输入框 + 跳转按钮**。
- 主页「加载」与「设置」之间新增**刷新**按钮（只刷新列表，不重新扫描磁盘）。
- **重新扫描弹窗（可折叠目录树）**：主页「重新扫描」弹出目录树，点箭头逐级展开（懒加载，大书库秒开）；复选框勾选一个或多个目录后只重扫选中子树，留空则全库重扫。新增轻量接口 `GET /api/list-dir?dir=`（每次只列一层子目录），替代原先一次性遍历全树的目录列表——大书库（约 5700 本）不会再因遍历过超时而列不出目录。
- **「书库目录结构与扫描规则」说明迁移**：从首页「全部书籍」标题后的 ⓘ 按钮/弹窗迁移到重新扫描弹窗标题下方（可折叠 `<details>`），内容按当前扫描规则重新生成（递归 20 层、忽略名单、封面优先级、未分类规则、短篇合并阈值规则）。
- **实时扫描进度**：扫描进行中时，主页顶栏「设置」左侧显示进度徽标——「扫描中 x/y 组 · 已发现 N 本 · 耗时」，悬停可看当前扫描目录；扫描结束徽标自动消失并刷新列表。新增轻量接口 `GET /api/scan-progress`（只返回进度状态，轮询不携带全量书单），全库扫描与目录重扫均支持。
- **自动扫描策略（可配置）**：宿主自带的「插件自动更新」会每天错峰重新加载插件，而原版每次插件启动都会无条件全库重扫一次（大书库耗时很久，表现为「没点重新扫描却一直在扫」）。现可在设置→「自动扫描」选择：距上次扫描超过阈值才扫（默认，阈值 72 小时）/ 每次都扫（原版行为）/ 仅当书库缓存为空时扫 / 从不自动扫描。重扫弹窗底部会显示「上次全库扫描：x 小时前」。
- **设置弹窗居中 + 加宽**：设置项增多后弹窗由底部贴边改为屏幕居中显示（最大宽度 600px、92% 宽、86vh 高，圆角 + 淡入动画）；「帮助文档」下方新增「修改版说明」入口，指向 GitHub 仓库 README。
- **增量扫描 + 断点续扫（大书库提速关键）**：
  - **分片缓存**：按顶层目录分组，每扫完一组就把该组结果写入分片缓存；中途插件被回收/重载也不会白扫，下次从已完成的分片继续（缓存只在整轮成功后整体生效，不会写坏数据）。
  - **成书目录签名复用**：每个成书目录按「音频文件名 + 非音频文件名 + metadata.json 修改时间」生成签名，签名未变就直接复用上次的书籍与章节，跳过全部音频 stat。
  - **整组快通道**：再进一步，若某个顶层组下**所有目录的 mtime 都没变**，则整组连目录遍历都跳过，直接复用缓存结果。
  - 实测（约 400 本的小库）：首次全量约 16 分钟 → 增量后 9 分钟 → 快通道生效后 **32~35 秒**。
  - 手动重新扫描时可勾选「强制全量」忽略分片缓存；`POST /api/rescan` 也支持 `{force:true}`。
  - 诊断字段：`GET /api/scan-progress` 返回 `reused`（复用本数）、`fastHit`/`fastMiss`（快通道命中/未命中组数）、`fastProbe`（首个未命中目录的期望与实际 mtime，用于排查）。

### 四、删除与清理

- **删除整本书**：卡片新增删除按钮，醒目确认弹窗（删除后不可恢复），连带删除书库文件夹；确认弹窗按书籍类型显示不同警告，删除结果按类型给出明细（`keptFolder` / `audioRemoved` / `collection` / `memberCount` 等诊断字段）。
- **删除「未分类」合集**：仅删除该文件夹下的音频文件，文件夹本身保留（避免误删目录里可能混着的图片/文档），删除后书目从列表移除。
- **删除「短篇合集」**：遍历合集成员（`memberIds`）逐个删除各短篇的文件夹，并清理合集与全部成员的收藏/自定义书名/倍速/播放进度记录。
- **删除按钮全类型可用**：未分类与合集的删除按钮不再置灰，悬停提示各自的实际删除行为。
- **最近播放清理**：支持一键清空全部播放记录（二次确认），单条记录卡片右上角 ✕ 单独删除。
- **清除播放进度**：详情页一键清除该书所有章节的播放记录（二次确认），配合重新听。
- 新增 `POST /api/clean-empty-dirs` 空目录清理接口。

### 五、播放体验

- **播放速度按书记忆**：倍速循环 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2，按书独立保存（localStorage + 服务端 `playbackRates`），换书/刷新后自动恢复；详情页与播放器页均显示本书当前速度。
- **播放/暂停按钮切换**：卡片播放按钮播放中变两条竖线 ❚❚，点击暂停、再点恢复；播放另一本书时上一本自动恢复 ▶，跨卡片状态实时同步。
- **详情页操作栏**：`继续播放 / 从第一集播放 / 暂停 / 播放速度 / 清除播放进度 / 收藏 / 刷新`
  - 「继续播放」自动定位到**进度最大的未完成章节**续播；
  - 暂停/播放与倍速按钮随 audio 事件实时同步。
- **修复自动跳章 bug**：原版章节播放完毕时 `ended`/`pause`/兜底定时器重复触发跳章，导致连跳两章（如 1→3）且中间章节被误标 100%。已加音频级 `_advancing` 锁，在新章节 `loadedmetadata` 及预加载超时时释放。

### 六、其他

- 全部前端修改集中在 `app.bundle` 注入（`index.html` 实际只加载该文件），HTML/CSS 层同步扩展；所有补丁带单次出现断言，构建即校验。

## 构建

```bash
python build.py            # 提取 vendor/audiobook.jsplugin.zip → 应用补丁 → 输出 dist/audiobook.jsplugin.zip
```

构建路径均可环境变量覆盖：

| 变量 | 说明 | 默认 |
|---|---|---|
| `AUDIOBOOK_SRC_ZIP` | 官方原包路径 | `vendor/audiobook.jsplugin.zip` |
| `JSC_EXE` | QuickJS 字节码编译器 | 本机 `@songloft/jsc-win32-x64` 安装路径 |
| `PLUGIN_VERSION` | 插件版本号 | `1.3.14` |

### CI 自动打包

`.github/workflows/build.yml`：

- push 到 `main` / `master` → 自动构建并上传构件；
- push `v*` tag → 自动构建并**创建 GitHub Release** 附带 `audiobook.jsplugin.zip`（版本号自动取 tag 名）。

```bash
git tag v1.3.14 && git push origin v1.3.14   # 即发布一个新版本
```

### 部署测试（本机多宿主）

node deploy.js                        # 同时部署到两台已配置的 Songloft 宿主（HTTP 热重载）

## 版本更新记录

### v1.3.35（打散合集支持选择成员 + 弹窗交互优化）

- **打散合集改为可选成员的部分打散**：详情页点「打散合集」不再直接打散整个合集，而是弹出**成员选择弹窗**——列出合集中全部成员（书名 + 复选框，默认全选），支持「全选/全不选」切换；确认后只移出勾选的成员，未勾选的保留在合集中。
  - 自动合集（shorts）：勾选的短篇写入忽略名单不再被自动合并，全部移出则合集消失；
  - 自定义合集/合集包：勾选的成员从合集移除并恢复显示，全部移出则合集自动删除；
  - 不勾选任何成员直接确认 = 打散整个合集（与原行为一致）。
- **新接口**：`GET /api/books/:id/members`（合集成员清单，含标题）；`POST /api/books/:id/scatter` 接受 `{ids:[...]}` 部分打散，响应新增 `partial/removed/remaining/gone` 字段，前端据此提示「已移出 N 个成员，合集还剩 M 个成员」。
- **「存为合集 / 创建合集包」弹窗去掉类型下拉**：点哪个按钮就固定创建哪种类型（弹窗标题、说明文字、确认按钮文案随类型变化），不再需要手动选类型。
- **主页移除「只看收藏」复选框**：筛选下拉已含「收藏」选项，二者重复；相关事件绑定改为空值保护。
- 实测（69）：custom/pack/shorts 三类合集的部分打散、成员恢复、全部移出自动删定义、忽略名单恢复均通过；弹窗用真实产物代码 + stub API 驱动浏览器验证（默认全选、部分确认载荷 `{"ids":[...]}`、toast 提示、全选/全不选切换）。

### v1.3.34（修复：详情页操作栏按钮嵌套导致空白按钮 + 显隐错乱）

- **修复详情页出现空白椭圆按钮、「重新扫描」变成裸文本**：v1.3.33 的 JG4h 补丁只替换了「重新扫描」按钮的**开始标签**，把完整的「打散合集」按钮插进了它的内部——HTML 不允许按钮嵌套，浏览器解析器把外层按钮截成空壳（收藏旁的空白椭圆）、「🔄 重新扫描」文字脱离按钮样式、`hidden` 显隐全部错位。现改为替换**完整按钮元素**，两颗按钮各自独立闭合。
- **显隐规则修正**：「打散合集」仅对自动合集（shorts）/自定义合集/合集包显示，未分类（misc）不再误显示（点了也只会报错）；「重新扫描」对纯虚拟合集隐藏，未分类目录书保留（其 folderRelPath 指向真实目录，重扫有意义）。
- 已用真实浏览器对 普通书/shorts/custom/pack/misc 五种书型做 DOM 解析验证，按钮渲染与显隐全部正确。

### v1.3.33（修复：合集包改为播放列表语义 + 详情页打散 + 按钮报错）

- **合集包语义修正（播放列表）**：合集包不再隐藏原有书籍——它与自定义合集不同，定位类似播放列表：把选中的有声书**按勾选顺序**串成一本可连续播放的虚拟书，原书保持可见。打包成员章节拼接、成员按选择顺序排列，移除合集包不影响任何原书。
- **「存为合集」与「创建合集包」拆分为两个按钮**：多选工具栏不再合并为一个入口，两个按钮各自带 tooltip 说明区别（合集=收纳整理、隐藏成员；合集包=连播顺序、保留原书），弹窗表单也按所选按钮预置类型并给出对应提示。
- **详情页打散**：自定义合集/合集包/自动短篇合集的详情页新增「打散合集」按钮，新接口 `POST /api/books/:id/scatter` 与列表页打散完全等效（只删定义/写忽略名单，不动文件）；此前仅批量编辑入口和列表页可用。
- **修复播放/编辑/删除/重新扫描/倍速按钮全部报错**：`ReferenceError: __relPath/__saveRate/__restoreRate is not defined`——这些函数在早前的补丁迭代中从启动块里意外丢失，现已恢复定义（含 `__savePrefs`），相关按钮恢复可用。
- **自动合集打散可恢复（诊断接口）**：新增 `GET/POST /api/debug/ignore-list`——查看/清空/移除 `ignoredShortsMembers` 忽略名单，误打散自动合集后可恢复（移除名单后重建合集即重新合并）。
- 修复设置加载时全局镜像 `__CSET` 不刷新的问题（个别场景读到旧配置）。

### v1.3.32（第四组：自定义合集 + 合集包 + 打散 + 主页筛选）

- **多选存为合集**：多选模式下勾选若干本书 → 批量工具栏新增「存为合集」→ 输入名称创建自定义合集；选中的全部是自定义合集时可创建**合集包**。
- **虚拟合集书**：自定义合集/合集包与自动短篇合集一样物化为虚拟书（章节 = 成员章节按书拼接、封面取首个成员、简介自动汇总成员清单），成员书隐藏不再重复显示。
- **打散**：删除自定义合集/合集包 = 打散，只删定义、成员立即恢复显示，**不删除任何文件**；删除确认弹窗与结果提示均有专门文案。
- **主页筛选下拉**：「全部书籍」旁新增筛选（全部 / 收藏 / 自动合集 / 自定义合集 / 合集包），与搜索、只看收藏可叠加使用。
- **持久化**：合集/包定义存于插件设置（与别名、覆盖层同库），重新扫描、忽略缓存扫描、插件重载都不会丢失；扫描完成后自动重新物化。
- 详情页「重新扫描」按钮对虚拟合集自动隐藏（无对应目录）。

### v1.3.31（多选工具栏补「反选全部」）

- 批量工具栏原有「本页反选」只能翻转当前页，「全选全部」没有对应的反向操作。现新增「反选全部」：对符合当前搜索/只看收藏过滤的**全部书籍**（跨页）执行选中状态翻转。

### v1.3.30（修复：卡片模板引号缺失导致整页卡片塌缩 + 最近播放区块消失）

- **修复书籍卡片全部塌缩成一个节点**（表现为：大图标/小图标只显示一个、列表显示异常）：v1.3.27 给卡片加删除按钮时，`title` 属性漏了收尾引号，未闭合的属性把后续所有卡片标记吞进属性值，浏览器解析后整页只剩一个巨型节点。本地 Mock 治具 + 无头浏览器复现定位，补上引号后三种视图均恢复正常。
- **修复「最近播放」区块一直隐藏**：早期版本在启动函数里插入了从未定义的 `__initViewMode()`，启动即抛异常，其后的最近播放渲染（`Y()`）从不执行。已改为安全调用显示方式同步函数。
- 顺带说明：v1.3.29 修复的「显示方式下拉无 change 绑定」是同一组症状的另一半——切换无效 + 卡片塌缩叠加，才呈现为"列表不正常、图标只显示一个"。

### v1.3.29（修复：显示方式切换失效 + 旧目录说明残留 + 重扫弹窗加宽）

- **修复「显示方式」下拉无效**：v1.3.11 接线时只加了读取/保存函数，漏绑了下拉的 change 事件——切到大图标/小图标/列表一直没有效果。现已绑定（切换即时生效并记忆），页面加载时也会把下拉同步到上次选择的模式。
- **清除页面底部残留的旧版「目录结构说明」**：v1.3.27 迁移说明到重新扫描弹窗时，删除旧弹窗的正则只删掉了外壳，正文块（目录树示例）和多余闭合标签残留下来直接渲染在书籍列表下方，现已整体移除。
- **重新扫描弹窗加宽**：默认 480px 放不下目录树与勾选列表，现加宽至最大 880px（94% 宽度）。

### v1.3.28（第三组：多选 + 批量删除/收藏/编辑）

- **多选模式**：「全部书籍」标题后新增「多选」切换按钮；进入后卡片左上角显示复选框，点击卡片任意位置切换选中（大/小图标/列表三种视图通用），选中卡片高亮描边。顶部批量工具栏显示已选数量，提供本页全选 / 本页反选 / 全选全部 / 清除选择——「全选全部」跨页生效（新接口 `GET /api/book-ids`，跟随当前关键词与只看收藏过滤）。
- **批量删除**：逐本调用既有 `DELETE /api/books/:id`（完整复用第二组的按类型删除逻辑：普通书删整个文件夹、合集删成员文件夹、未分类仅删音频），二次确认 + 逐本进度 + 成功/失败汇总。
- **批量收藏/取消收藏**：新接口 `POST /api/batch/favorite`，按传入状态**显式设置**（非翻转），不受当前勾选前状态影响。
- **批量编辑**：新接口 `POST /api/batch/edit`，支持——简介**前插/后插**（在当前生效值上追加）；分类/标签/作者的**追加**（标签按中英文逗号/顿号/空格分词去重合并）、**替换**（设为新值）、**重设**（清除覆盖，回落扫描值）。所有编辑保存在 `settings.bookEdits` 覆盖层（按书 id 存），**不写 metadata.json、不改书库索引，重扫不丢失**；列表/搜索/分类过滤/详情页均基于覆盖后值显示，与手改一致。
- **封面重设**：改版自定义封面机制——`updateCover` 覆写 `cover.jpg` 前先把原封面备份到插件目录 `cover_backup/<id 哈希>.jpg`（仅首次，重复改封面不覆盖备份）；`POST /api/batch/cover-reset` 从备份恢复原封面并清理备份。缓存清理只清 `.cache/transcode`，不影响备份。此前（v1.3.27-）改过的封面没有备份，重设时如实报告「无备份」跳过。
- 修复：删除确认弹窗对「仅按 id 识别的未分类书」的警告文案误引用弹窗元素 id 的小 bug。

### v1.3.27（第二组：未分类/合集可删除 + 目录结构说明迁移 + 设置弹窗改造）

- **未分类可删除（仅删音频）**：`DELETE /api/books/:id` 对未分类书目改用新逻辑——只删除目录下全部音频文件（按扩展名 `.mp3/.m4a/.m4b/.wav/.aac/.flac/.ogg/.wma/.opus/.ape/.wv/.tta/.mp2/.ac3` 识别），文件夹本身保留，返回 `keptFolder:true` 与 `audioRemoved` 计数。删除按钮解除置灰，确认弹窗与结果提示按类型区分。
- **短篇合集可删除（删成员文件夹）**：`virt:"shorts"` 的合集走专属分支——遍历 `memberIds` 逐个删除各短篇的文件夹，并从库中清理合集及全部成员的书目、章节、收藏、自定义书名、倍速记录；返回 `collection:true` 与 `memberCount`。前端确认弹窗提示「将删除合集内 N 本短篇各自的文件夹」。
- **删除响应增加诊断字段**：`keptFolder` / `audioRemoved` / `collection` / `memberCount`，前端据此给出「已删除合集「X」及其 N 本短篇」「已删除音频文件，文件夹已保留」等精确提示。
- **目录结构说明迁移**：移除首页「全部书籍」后的 ⓘ 按钮及旧的说明弹窗，改为在重新扫描弹窗「重新扫描」标题下方新增可折叠的「书库目录结构与扫描规则」说明（按现行规则重写：递归 20 层、`@eaDir` 等忽略名单、封面文件优先级、未分类与短篇合并规则）。
- **设置弹窗改造**：改为屏幕居中（不再底部贴边），最大宽 600px / 高 86vh，圆角淡入动画；「帮助文档」下方新增「修改版说明」，链接到 GitHub 仓库 README。
- 实测（69 服务器）：未分类删除移除 279 个音频且保留文件夹；合集删除 `memberCount:1` 后成员文件夹及合集目录均从磁盘移除、书目无残留。

### v1.3.26（第一组：详情页重扫 + 短篇合并阈值不再自动重扫）

- **详情页「重新扫描」按钮**：在书籍详情页「刷新」之前新增「重新扫描」按钮。点击后强制重扫该书所在目录（`force:1`），可解决音频数增减、音频内容替换（时长变化）、音频重命名等变更。该书位于书库根目录时提示改用主页「重新扫描」。
- **短篇合并阈值改动不再自动重扫**：设置里修改「短篇合并阈值」只保存并提示用户，不再自动触发全库扫描。修改后不会立即生效，需用户手动点「重新扫描」并选「仅重建合集」即可按新阈值即时重算（不读盘，秒级）。
- **重扫弹窗三模式**：增量扫描（默认，只重扫有变动的目录）/ 仅重建合集（不读盘，按当前阈值重跑短篇合并）/ 忽略缓存强制全量（音频被替换但文件名没变时用）。
- **短篇合并改为隐藏子书**：合并后的短篇子书打 `hidden`+`mergedInto` 标记并从书单/分类/书数过滤，不再从库中删除，使「重建合集」可纯内存重跑、后续「打散」能还原子书。
- **修复目录重扫静默失败**：将 `__U`/`__D`（目录扫描核心）提升到模块级，修复「`__D is not defined`」导致指定目录重扫静默失败的问题；并给目录重扫路径做 M 前缀归一化（兼容传入完整路径）。
- 扫描进度接口新增 `lastError` 字段，便于诊断重扫异常。
